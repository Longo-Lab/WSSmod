# List Available Prebuilt WSS Reference Sets

List Available Prebuilt WSS Reference Sets

## Usage

``` r
list_prebuilt_wss()
```

## Value

A character vector of prebuilt reference set names usable as the
`prebuilt` argument of
[`calculate_WSS()`](https://Longo-Lab.github.io/WSSmod/reference/calculate_WSS.md)
and
[`load_prebuilt_wss()`](https://Longo-Lab.github.io/WSSmod/reference/load_prebuilt_wss.md).
